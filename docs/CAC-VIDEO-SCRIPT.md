# Wisp demo video script (target 2:45, check the official time limit)

Rule: say everything in your own words. Replace [brackets]. Record the screen live, no cuts over errors.

| Time | On screen | You say |
|---|---|---|
| 0:00–0:20 **Problem** | You, or a stuck-looking screen (homework, confusing software) | "[One statistic, with source.] When you're stuck, help is either not private, not free, or not where you're working. I built Wisp to fix that." |
| 0:20–0:35 **What it is** | Notch appears, hotkey held | "Wisp lives in your Mac's notch. Hold two keys, ask, let go. It sees your screen and answers. Everything runs on this laptop. Nothing is uploaded." |
| 0:35–1:05 **Demo 1: point** | Ask "where do I click to [task]?" | Wisp marks the exact button. "It finds the real button using the accessibility tree and on-device text recognition, not a guess." |
| 1:05–1:40 **Demo 2: explain** | Drag-select a hard problem, ask "why?" | Handwritten step-by-step notes appear. Click Next through them. "It works the problem beside the problem, then I can save it as a study sheet." |
| 1:40–1:55 **Demo 3: safe** | A confirmation card (e.g. before sending a text) | "It never sends, deletes or pays without asking first." |
| 1:55–2:25 **Code** | Editor: 10–15 lines of code you chose | "This is how it picks what to point at: [explain the matching in plain words]. I wrote [X] and I'm using [library] for [Y]." |
| 2:25–2:45 **Impact** | Your testers / quote | "[N] students tried it. [Quote.] Next I want to [one goal]. Thank you." |

## Before you record
- Screen-record at 1080p, mic close, quiet room, captions on.
- Close notifications; use a clean desktop; hide personal messages, email, contacts.
- Do a dry run of each demo three times. Pick the ones that work every time.
- Practice the code segment until you can explain it without reading.
